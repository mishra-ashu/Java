🚀 Getting Started
1. Clone the repository
git clone https://github.com/mishra-ashu/Java.git

2. Navigate to the project
cd Java

3. Compile a Java program

For example:

javac firstprog.java

4. Run the program
java firstprog


For another example:

javac StudentManagementSystem.java
java StudentManagementSystem

💡 Why This Repository?

Instead of only relying on Java's built-in functionality, several examples in this repository explore how common data structures and algorithms can be implemented and understood using Java.

The goal is learning by implementation — writing code, experimenting with it, and understanding the logic behind each concept.
